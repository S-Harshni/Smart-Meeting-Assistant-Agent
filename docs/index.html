Overview

Meeting notes pile up and the follow-up work gets lost. This workflow reads the notes, writes a structured summary, opens one Linear issue per action item and posts the decisions to Slack.

Agents are orchestrated with Agno workflows on an open-weights LLM (Kimi-K2-Instruct) served by Nebius AI Studio. The app needs API keys to run, so this page shows how it works; clone the repository to try it.

Highlights

  • Transcription agent with sandboxed file tools writes a structured summary: goals, costs, stack, timeline, owners, deadlines
  • Linear agent creates one issue per action item with title, description, assignee and deadline
  • Slack agent posts a recap with decisions, tasks and next steps
  • Slack and Linear steps run in parallel and are added only when their keys are provided
  • Keys stay in the user's session and are never written to environment variables

How it works

  1. 01

    Read the notes

    The transcription agent reads the uploaded notes from a per-run temporary folder and writes a structured summary.

  2. 02

    Act on them

    The Linear and Slack agents run in parallel: one creates tasks, the other posts the recap.

  3. 03

    Summarise

    The summary agent produces the final Markdown summary shown in the app.
